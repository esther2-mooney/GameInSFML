# GameInSFML

This is just a blank repository for a SFML C++ project, but using the formatting from the UWE Games Technology course projects.

If you want to change the name of the project from "GameInSFML", then open the CMakeLists.txt BEFORE opening the project in software, and ctrl+F replace the phrase "GameInSFML" with whatever you want to change it to.

This repo is a template, so just click "Use this template" and choose "Create a new repository". You should probably call it the same thing that you used instead of "GameInSFML".
